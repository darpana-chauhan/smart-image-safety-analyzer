# 🛡️ Smart Image Safety Analyzer  
### Computer Vision + NLP | AI Safety Project

An **AI-powered Smart Image Safety Analyzer** that analyzes real-world images and identifies potential safety risks using **vision-language models**.  
The system detects whether a person is wearing a helmet and provides **clear safety recommendations** based on the analysis.

## 🔍 Key Features

- Detects helmet presence in images
- Classifies situations as **SAFE** or **UNSAFE**
- Generates actionable safety advice
- Built using modern **Vision + Language AI models**
- Simple and interactive **Streamlit UI**

---

## 📌 Demo Results

- ✅ Image with helmet → **Marked as SAFE**
- ❌ Image without helmet → **Flagged as UNSAFE**
- 🧠 Context-aware safety suggestions are provided automatically
